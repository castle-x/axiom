# @castle-xx/axm-preview

Standalone Axiom `.axm/` knowledge base previewer.

```bash
npx @castle-xx/axm-preview --target=/path/to/project
```

Or install it globally:

```bash
npm install -g @castle-xx/axm-preview
axiom-preview --target=/path/to/project --port=8765
```

The package bundles prebuilt `axiom-preview` binaries for macOS, Linux, and Windows.
